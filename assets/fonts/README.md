# Fonts

`TitanOne-Regular.ttf` — used for the title screen heading. Chunky playful
display face, which is why it suits a tropical game title.

Licensed under the SIL Open Font License 1.1 (see `TitanOne-OFL.txt`). That
permits bundling in a commercial game; the licence file must ship with it, which
is why it lives here rather than being pasted into a credits screen only.

Everything else uses Godot's default font, emboldened at runtime via
`FontVariation` in `scripts/ui/ui_theme.gd` — no second font file needed.
